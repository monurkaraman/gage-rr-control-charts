# Gauge R&R Control Charts

Shiny app for the Real Time Gage R&R. Requires R with `shiny` and `readxl`.

Run with `shiny::runApp("app.R")`.
The user can upload their own data or,
The `data/` folder contains simulated example data
(generated by `generate_sample_data.R`):

- `phase1_baseline.xlsx`: Phase 1 data (in control)
- `phase2_A_in_control.xlsx`: Phase 2, no change
- `phase2_B_repeatability_shift.xlsx`: repeatability increases after window 5
- `phase2_C_part_variance_shift.xlsx`: part variance increases after window 5
- `phase2_D_part_variance_reduction.xlsx`: part variance decreases after window 5

Upload the Phase 1 file and click "Run Phase 1", then upload a Phase 2 file
and click "Add Phase 2 Data".
